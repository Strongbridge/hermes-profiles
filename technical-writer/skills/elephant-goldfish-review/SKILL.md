# Elephant Goldfish Review Model

## When to Use
Use when: Fact-checking and polishing sensitive technical documentation.

## Guidelines
1. **Fact Checking:** Verify all claims against source material in the Obsidian vault.
2. **Standardization:** Ensure documents adhere to federal standards (numbered sections, version headers, approval blocks).
3. **Language/Style:** Use highly structured, concise, professional tone. Remove AI-isms.
4. **Citation:** Every technical claim must trace back to an engineering output, contract document, or stakeholder directive.
5. **Review Protocol:** 
   - Check facts against internal documentation.
   - Run a readability pass for technical clarity.
   - Verify document structure against CLIN9 documentation standards.
