# 50-State Procurement Intelligence Guide

This reference provides architectural and tactical guidance for researching, tracking, and capturing state and local (SLED) government IT contracts across all 50 states.

---

## 1. The 50-State Procurement Ecosystem

State procurement is fundamentally decentralized across 50 independent state statutes, e-procurement portals, and regional cooperatives. There is no single "State SAM.gov".

To capture opportunities across all 50 states, use a four-tiered approach:
1. **National Cooperatives**: Single-agreement multi-state contracts (NASPO ValuePoint, OMNIA Partners, Sourcewell).
2. **State Master Contracts**: Pre-qualified vendor lists for state agencies (e.g., MD CATS+, VA VITA ITCL, TX DIR DBITS, CA CMAS).
3. **Direct State Portals**: Central bidding boards (eVA, Cal eProcure, TxSmartBuy, eMMA, eMarketplace).
4. **SLED Data Aggregators**: Multi-state data feeds (HigherGov, GovWin IQ, GovTribe, BidNet Direct, Periscope S2G).

---

## 2. NASPO ValuePoint Lead-State Model

NASPO ValuePoint operates under a cooperative purchasing structure:
1. **Lead State Solicitation**: One state issues a competitive RFP on behalf of NASPO members (e.g., Utah leading Cloud and Software Solutions 2026–2036).
2. **Master Agreement Award**: Multi-award contracts granted to prime providers and resellers (e.g., Carahsoft, SHI, WWT, Presidio).
3. **State Participating Addenda (PAs)**: Individual states execute a PA adopting the master contract with state-specific terms.
4. **Agency Piggybacking**: State DOTs, universities, and municipalities order directly against the PA without separate public bids.

### Subcontractor Capture Strategy
*   Partner with awarded master agreement holders as an authorized professional services or implementation subcontractor.
*   Monitor state purchasing boards for new PA signings to identify prime contractors authorized to sell in target states.

## 3. Commodity Code Taxonomies (NIGP & UNSPSC)

State portals filter solicitations by commodity classification rather than NAICS codes.

### NIGP Commodity Codes (~35 States)
*   **Class 920 (Data Processing, Computer, Programming, and Software Services)**:
    *   `920-03`: Application Development Services
    *   `920-40`: Programming Services
    *   `920-45`: Software Maintenance and Support
    *   `920-64`: System Implementation and Integration
*   **Class 918 (Consulting Services)**:
    *   `918-28`: Computer Systems Consulting
    *   `918-29`: Software Consulting & Architecture
*   **Class 208**: Application Software for Microcomputers/Mainframes

### UNSPSC Commodity Codes (~10 States)
*   `81111508`: Application Development Services
*   `81111801`: Computer System Architecture / Engineering
*   `81112200`: Software Maintenance and Support

## 4. Key State DOT Master Contract Vehicles

| State & Agency | Master Contract Vehicle | Portal | Scope & Key Functional Areas |
| :--- | :--- | :--- | :--- |
| **Maryland (MDOT)** | CATS+ (Consulting and Technical Services+) | eMMA | Functional Area 5 (Software Engineering), FA 7 (Security), FA 10 (IT Consulting). 35% MBE participation goal. |
| **Virginia (VDOT)** | VITA ITCL (IT Contingent Labor) & Statewide Contracts | eVA | Hourly staff augmentation and deliverables-based SOW projects under $2M; ongoing O&M monthly fee engagements. |
| **Texas (TxDOT)** | DIR DBITS (Deliverables-Based IT Services) & ITSAC | TxSmartBuy / DIR | Category 1 (App Dev, Migration, ERP), Category 2 (BI, Analytics, Data Management). SOW approval required over $50K. |
| **California (Caltrans)** | CMAS (California Multiple Award Schedules) | Cal eProcure | Based on federal GSA Multiple Award Schedules (MAS); streamlined ordering for software modernization and GIS. |
